# Africa Healthcare — Combined Unified Release

This release consolidates all previously iterated versions into a single platform baseline:

- Secure backend API with token auth, validation, consent gate, data residency enforcement, and explainable AI triage.
- Dynamic frontend with configurable widgets, consent manager, privacy panel, and offline-safe triage queue/sync.
- Local-first data persistence for consent/preferences/audit for low-connectivity deployments.
- CI workflow, Docker assets, Kubernetes manifests, and architecture/security/API docs.
