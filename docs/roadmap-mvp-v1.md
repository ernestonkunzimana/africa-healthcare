# Milestone Roadmap: MVP → V1

## MVP (0–3 Months)

- Deliver clinician web app + triage API + auth baseline.
- Add event logging, observability dashboard, and secure deployment pipeline.
- Pilot in one region with localized language packs.

## M1 (3–6 Months)

- Integrate telemedicine module and appointment orchestration.
- Add patient mobile app and provider scheduling portal.
- Integrate FHIR-compatible EHR adapter.

## M2 (6–9 Months)

- Introduce AR-assisted remote triage overlays.
- Add offline-first capability for low-connectivity environments.
- Expand AI guardrails with region-specific clinical policy packs.

## V1 (9–12 Months)

- Multi-country launch with tenant isolation and compliance presets.
- Blockchain-backed immutable care event notarization.
- Advanced clinical copilots with bounded autonomy and real-time safety observability.
